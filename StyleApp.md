NeoBrutal EdTech Slides Skill

1. Skill Identity

Skill name: NeoBrutal EdTech SlidesPurpose: Create bold, friendly, structured educational slides using a hybrid of Neo-Brutalism, Swiss/International Style, Memphis geometry, and modern EdTech / Creator Economy aesthetics.

Core style definition

Playful Neo-Brutalist EdTech presentation with Swiss editorial grid, oversized bold sans-serif typography, cream and saturated pastel color palette, thick black outlines, hard offset shadows, rounded cards, pill labels, rectangular keyword highlights, geometric Memphis accents, strong left alignment, generous whitespace, modular information cards and highly structured educational storytelling.

Style blend

Neo-Brutalism: ~55%

Swiss / International Style: ~25%

Memphis Design: ~10%

Modern EdTech / Creator Economy: ~10%

The style should feel:

bold

friendly

modern

educational

structured

editorial

approachable

creator-led rather than corporate

2. Design DNA

The visual identity is driven by 8 core principles:

Oversized bold typography

Thick black outlines

Hard offset shadows

Saturated pastel colors

Cream or flat-color backgrounds

Large rounded cards

Strong Swiss-style grid alignment

Semantic text highlights

If several of these disappear, the deck will no longer feel like the intended style.

4. Text Highlight Rules

Use rectangular background highlights for semantic emphasis.

Example:

AI không chỉ TRẢ LỜI
AI có thể HÀNH ĐỘNG

Highlight only the most important phrase.

Recommended rule:

Highlight ratio: 15–25% of headline

Do not highlight an entire headline unless absolutely necessary.

Highlight blocks:

square or very slightly rounded

minimal padding

usually yellow, mint, coral, or another accent

black text

Cards may be rounded, but headline highlights should usually remain more rectangular.

10. Grid System

Use a clear Swiss-style grid.

For a square 1080×1080 slide:

Outer margin: 55–70 px
Grid: 12 columns
Gutter: 18–26 px

Simplified alignment anchors:

Left alignment line ≈ 64 px
Right alignment line ≈ 1016 px

Alignment rule

Prefer left alignment.

Use center alignment only for:

numbers in circles

compact icons

selected CTA text

isolated badges

Avoid centering entire content sections.

11. Negative Space

Leave 20–35% of the slide visually empty.

Do not fill every available area.

Whitespace is part of the design.

A slide should usually contain:

1 hero area
+
1 content system

Avoid combining headline + diagram + table + chart + quote + photo + CTA on one slide.

16. Bullet Style

Avoid default PowerPoint bullets.

Use small accent circles with black outline.

Example:

23. Content Density Rules

Avoid text-heavy slides.

Recommended word count

Hero slide:

20–45 words

Normal content slide:

50–100 words

Dense content slide:

Max ~130 words

If content does not fit:

shorten wording

split cards

change layout

split into another slide

Never shrink body text below a readable minimum simply to fit content.

32. Asymmetric Swiss Composition

Prefer balanced asymmetry.

Example:

Large headline on left
Geometric decoration on right

Do not force symmetry unless the content demands it.

33. Visual Hierarchy

Each slide should have four levels:

Level 1 → Headline / focal point
Level 2 → Cards / diagram
Level 3 → Supporting text
Level 4 → Footer / metadata

The headline must clearly dominate.

If the footer competes with the headline, the hierarchy is wrong.

34. Text Width

Keep body text readable.

Recommended:

roughly 45–70 characters per line

avoid full-width paragraphs

If text becomes too wide:

reduce column width

insert line breaks

split content into cards

35. Overlap Rules

Allowed:

decorative circles may overlap

small geometric accents may overlap

Avoid:

card-on-card overlap

text colliding with shadows

important content entering margins

36. Anti-Corporate Rules

Do not use:

glassmorphism

Do not create generic:

+
6 bullets
+

38. Photography Rules

Default:

no photography

If photography is required:

use cutout photography

add black outline if appropriate

place on simple flat background

do not use generic full-screen stock photos

Typography should remain the main hero.

39. Signature Elements

At least one or two should appear on most slides:

Black pill eyebrow

Hard-shadow card

Rectangular keyword highlight

Number circle

Pastel color-coded cards

These elements create recognizability across the deck.

40. Recommended Style Balance

Maintain approximately:

65% clean / structured
35% playful / brutalist

Avoid pushing brutalism so far that:

text becomes overly heavy

borders become crude

colors become harsh

layout becomes chaotic

41. Slide Generation Logic

When generating a slide:

Step 1 — Identify content type

Classify the content as:

comparison

list

roadmap

architecture

metric

summary

CTA

Step 2 — Select layout archetype

Use semantic mapping.

Step 3 — Choose dominant background

Use the deck rhythm and content type.

Step 4 — Create headline

Shorten to:

4–12 words

maximum 3 lines

Step 5 — Identify semantic highlight

Highlight only 1 key phrase if useful.

Step 6 — Transform information into components

Prefer:

cards

number badges

module blocks

rows

diagrams

Avoid raw bullet dumping.

Step 7 — Apply tokens

Use:

palette

borders

shadows

radius

spacing

typography

Step 8 — Validate density

If crowded:

shorten

split

change layout

Step 9 — Add optional decoration

Use 1–3 geometric shapes only when they improve balance.

Step 10 — Add consistent footer

Maintain baseline and brand continuity.

42. Quality Control Checklist

Before finalizing each slide, verify:

Is the headline large enough?

Is there one obvious focal point?

Is the slide too text-heavy?

Is the palette correct?

Is there any gradient? Remove it.

Are primary cards outlined in black?

Are shadows hard rather than blurred?

Are there too many colors?

Is text mostly left-aligned?

Is there enough negative space?

Is the footer aligned consistently?

Is there at least one signature component?

Does anything look like a generic PowerPoint template?

Are radius and border systems consistent?

Could a bullet list be converted into a more visual component?

Is body text still readable?

Is the slide communicating one dominant message?

Is the highlight semantic rather than decorative?

Are decorative shapes limited and purposeful?

43. Quality Failure Conditions

A slide fails the style if:

it uses gradients as a primary visual device

it has soft blurred shadows

it uses multiple unrelated font families

it uses tiny body text to force-fit content

it uses a generic title + bullet template

it lacks strong hierarchy

it contains too many decorative shapes

it looks overly corporate

it uses inconsistent card borders or radii

it has weak contrast

it is overly centered

it is visually crowded

Use this short style prompt when needed:

Modern playful Neo-Brutalist EdTech presentation with Swiss editorial grid, oversized bold sans-serif typography, thick black outlines, hard bottom-right shadows, cream and saturated pastel palette, rounded modular cards, pill labels, rectangular keyword highlights, restrained Memphis geometric accents, strong left alignment, generous negative space, flat colors, high contrast, and visual-first educational storytelling.
